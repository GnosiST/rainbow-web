# Portfolio Website

A modern portfolio website built with Next.js and TypeScript, featuring a unique desktop OS-style interface.

## Overview

This project showcases a creative approach to portfolio design, mimicking the look and feel of desktop operating systems like macOS and Windows.

## Key Features

- **Dual Theme Support**: Switch between macOS and Windows styles
- **Window Management**: Drag, resize, maximize windows
- **Responsive Design**: Adapts to mobile with iOS/Android themes
- **Smooth Animations**: Powered by Framer Motion

## Technical Stack

- Next.js 14 with App Router
- TypeScript for type safety
- Tailwind CSS for styling
- Zustand for state management
- Framer Motion for animations
